# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание

Проект представляет собой адаптивную версию многостраничного HTML/CSS-сайта интернет-магазина.
Основа перенесена из проекта КР №1 (`kr1-html-css-shop`).

## Практическая работа №12

Выполнено:

- создан отдельный репозиторий `kr3-responsive-shop`;
- перенесена основа проекта КР №1;
- добавлен файл `css/responsive.css` (подключён после `style.css` на всех страницах);
- проверен `viewport` на всех страницах;
- применён подход Mobile First (`min-width` медиазапросы: 640, 768, 900, 1024px);
- адаптирована навигация (колонка на телефоне, строка с 768px; sticky-шапка только с 768px);
- адаптирован hero-блок (1 колонка → 2 колонки с 900px, заголовок через `clamp()`);
- адаптирована сетка карточек (1 → 2 → 3 колонки);
- адаптирован каталог (фильтр над товарами на телефоне, sticky-сайдбар с 1024px);
- добавлены responsive images: `srcset` + `sizes` у карточки «Товар 1», `picture` в hero-блоке, `loading="lazy"`;
- адаптирована форма заявки (1 колонка → 2 колонки, поля высотой от 44px);
- адаптирована таблица характеристик (горизонтальный скролл внутри `.table-wrapper`);
- модальное окно ограничено по высоте и прокручивается;
- выполнена проверка через DevTools.

## Практическая работа №13

Тема: «A11y-аудит и обеспечение доступности. Использование Lighthouse и анализ проблем доступности».

Выполнено:

- проверена семантическая структура страниц (один `h1` на странице, порядок `h1 → h2 → h3`, `header`/`nav`/`main`/`section`/`article`/`aside`/`footer`);
- добавлена ссылка пропуска к основному содержимому (`.skip-link` → `#main`) на всех страницах;
- проверена навигация с клавиатуры (Tab / Shift+Tab / Enter / Esc);
- добавлен единый видимый фокус `:focus-visible` (3px) для всех интерактивных элементов;
- проверены изображения и alt-описания;
- проверены формы и связанные `label`;
- проверены кнопки и ссылки;
- исправлена контрастность отдельных элементов;
- проверено и доработано модальное окно;
- выполнен Lighthouse-аудит;
- сохранён Lighthouse-отчёт и скриншот;
- исправлены найденные проблемы доступности.

## Lighthouse

Категория: Accessibility, Lighthouse 12.6.1, режим «Навигация», эмуляция мобильного устройства.

| Страница | До исправлений | После исправлений |
|---|---|---|
| `index.html` | 100 | 100 |
| `catalog.html` | 100 | 100 |
| `product.html` | 100 | 100 |
| `order.html` | 100 | 100 |
| `contacts.html` | 100 | 100 |

Автоматических ошибок Lighthouse не нашёл уже до исправлений, поэтому основная часть
проблем была найдена ручной проверкой (раздел «Проверить вручную» в отчёте Lighthouse,
проход по сайту клавишей Tab).

Отчёт сохранён в папке `lighthouse/`:

- `lighthouse/accessibility-report.png` — скриншот отчёта для главной страницы;
- `lighthouse/accessibility-report-index.html` — полный отчёт `index.html`;
- `lighthouse/accessibility-report-catalog.html` — полный отчёт `catalog.html`;
- `lighthouse/accessibility-report-order.html` — полный отчёт `order.html`.

## Исправления доступности

| Проблема | Где | Исправление |
|---|---|---|
| Нет быстрого перехода к контенту, с клавиатуры нужно каждый раз проходить 9 пунктов меню | все страницы | добавлена `.skip-link` (скрыта за экраном, появляется при фокусе), у `main` — `id="main"` |
| Кнопка «Наверх» вела на несуществующий якорь `#top` | все страницы | `body` получил `id="top"`, стрелка скрыта от диктора (`aria-hidden`), понятный `aria-label` |
| Тонкий фокус (2px), на синих кнопках сливался с фоном | `style.css` | общий `:focus-visible` 3px + белый зазор `box-shadow` у синих кнопок |
| Sticky-шапка перекрывала элемент в фокусе | `responsive.css` | `scroll-padding-top: 140px` с 768px |
| Серый текст `#666` на сером фоне `#f7f7f7` на грани нормы | `style.css` | `--color-muted: #4b5563`, `--color-text: #1f2937` |
| Рамки полей формы `#ddd` почти не видны (контраст < 3:1) | `style.css` | рамки полей `#8a94a3`, у карточек и таблиц оставлена светлая рамка |
| Неинформативные alt («Товар 1») | `index`, `catalog`, `product` | осмысленные alt-описания |
| Кнопки «Заказать» / ссылки «Подробнее» одинаковые для диктора | `index`, `catalog` | скрытый уточняющий текст `.visually-hidden` («Заказать «Товар 1»») |
| В таблице заголовки строк были `td` | `product.html` | `th scope="row"`; обёртка таблицы доступна с клавиатуры (`tabindex="0"`, `role="region"`) |
| У модального окна только кнопка «Закрыть» внизу длинной формы | `index.html` | добавлена кнопка `×` с `aria-label="Закрыть окно"`, `aria-describedby` с пояснением |
| Ошибка формы обозначалась только красной рамкой | `index.html`, `main.js` | текстовая сводка ошибок `role="alert"`, рамка 2px, `aria-invalid` |
| Подсказка формата телефона не связана с полем | `index`, `order` | `aria-describedby` на подсказку |
| После закрытия модального окна фокус терялся | `main.js` | фокус возвращается на кнопку, которая открыла окно |
| Звёздочка обязательных полей не объяснена отдельно | `order.html` | `.form-note` + `aria-describedby` у формы |
| Текущая страница в хлебных крошках не отмечена | все страницы | `aria-current="page"` |
| Телефон и e-mail в контактах — просто текст | `contacts.html` | ссылки `tel:` и `mailto:` |
| Плавная прокрутка мешает людям с вестибулярными нарушениями | CSS | `prefers-reduced-motion: reduce` отключает анимации |

# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание

Проект представляет собой адаптивную версию многостраничного HTML/CSS-сайта интернет-магазина.
Основа перенесена из проекта КР №1 (`kr1-html-css-shop`).

## Практическая работа №12

Выполнено:

- создан отдельный репозиторий `kr3-responsive-shop`;
- перенесена основа проекта КР №1;
- добавлен файл `css/responsive.css` (подключён после `style.css` на всех страницах);
- проверен `viewport` на всех страницах;
- применён подход Mobile First (`min-width` медиазапросы: 640, 768, 900, 1024px);
- адаптирована навигация (колонка на телефоне, строка с 768px; sticky-шапка только с 768px);
- адаптирован hero-блок (1 колонка → 2 колонки с 900px, заголовок через `clamp()`);
- адаптирована сетка карточек (1 → 2 → 3 колонки);
- адаптирован каталог (фильтр над товарами на телефоне, sticky-сайдбар с 1024px);
- добавлены responsive images: `srcset` + `sizes` у карточки «Товар 1», `picture` в hero-блоке, `loading="lazy"`;
- адаптирована форма заявки (1 колонка → 2 колонки, поля высотой от 44px);
- адаптирована таблица характеристик (горизонтальный скролл внутри `.table-wrapper`);
- модальное окно ограничено по высоте и прокручивается;
- выполнена проверка через DevTools.
